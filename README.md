# betterthanjson.com

Standalone benchmark landing page for [GCF (Graph Compact Format)](https://github.com/blackwell-systems/gcf).

1,300+ LLM evaluations across 10 models and 3 providers. GCF averages 90.7% comprehension accuracy where JSON averages 53.6%. 79% fewer tokens. Wins all 6 datasets on TOON's own benchmark.

- [Live site](https://betterthanjson.com)
- [Full benchmarks](https://gcformat.com/guide/benchmarks.html)
- [GCF Specification](https://github.com/blackwell-systems/gcf)
